# Cheat Vault: website

Public pages for the Cheat Vault app (the app code lives in the private `gta6-cheats-app` repo), served by GitHub Pages:

- `privacy.html`: privacy policy (use this URL in App Store Connect / Google Play)
- `terms.html`: terms of use
- `codes.json`: the cheat list the app downloads on launch. **Bump `version` every time you change it**, or the app keeps its cached copy.
- `index.html`: landing page
